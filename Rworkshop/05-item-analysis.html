Workshop 5 — Item analysis

In this workshop: practise item difficulty and two measures of discrimination, then learn to calculate and interpret the item reliability index.

Open a new R script called Workshop05.R. Run each section in order. The data come with psych; no separate data file is needed.

About the LSAT6 data

The Law School Admission Test (LSAT) is used in law school admission. Our historical example, lsat6, contains responses from 1,000 people to five Figure Classification items, analysed by Bock and Lieberman (1970). The “6” identifies the section, not the number of items.

In the datasetMeaning
Each rowOne person’s responses.
Q1–Q5The five items: 1 = correct, 0 = incorrect.
Total scoreNumber correct across these five items, from 0 to 5.

For example, 1, 0, 1, 1, 0 gives a total of 3. There are no missing responses. The data contain scored answers, not question wording. Our five-item total is not an official scaled LSAT score.

Before you start

Use psych from Workshop 4. If needed, install it once with install.packages("psych").

# Before you start ----
# Run once if needed: install.packages("psych")
library(psych)         # load the package used in Workshop 4
options(scipen = 999)  # show ordinary numbers

1. Read the item data

# 1. Read the item data ----
data(bock, package = "psych")     # loads the LSAT example datasets
items <- as.data.frame(lsat6)     # keep section 6 as a data table
head(items)                      # look at the first six people
dim(items)                       # number of people and items
sum(is.na(items))                 # count missing responses

total <- rowSums(items)           # add the five scores for each person
table(total)                     # count people at each total score

data(bock) loads the LSAT datasets. as.data.frame() makes a table we can use with $; rowSums() adds each person’s item scores.

Show what you should see

You should see 1,000 rows, five columns, no missing responses, and totals from 0 to 5.

2. Item difficulty

For a 0/1 item, the mean is the proportion correct, p. Higher p means easier. It is not a significance-test p-value.

# 2. Item difficulty ----
mean(items$Q3)                    # proportion correct on Q3
p <- colMeans(items)              # proportion correct on every item
round(p, 3)                      # display three decimal places

colMeans() finds each column’s mean; round(..., 3) displays three decimals.

Try it: identify the easiest and hardest items.

Show answer

Q1 is easiest (p = .924); Q3 is hardest (p = .553). These values describe this sample.

3. Item discrimination

Do people with higher total scores tend to get an item right? We will examine this in two ways.

3.1 Upper–lower difference

Use the one-third and two-thirds score cutoffs, 3 and 4. Keep tied scores together, giving groups close to thirds:

GroupTotal scorePeople
Lower0–3345
Middle4357
Upper5298

D = pupper − plower

# 3. Item discrimination ----
# 3.1 Upper-lower difference ----
quantile(total, probs = c(1/3, 2/3))  # find the cutoff scores: 3 and 4

lower <- items[total <= 3, ]          # lower group: total scores 0 to 3
upper <- items[total > 4, ]           # upper group: total score 5
nrow(lower)                          # 345 people in the lower group
nrow(upper)                          # 298 people in the upper group

p_lower <- colMeans(lower)           # proportion correct in the lower group
p_upper <- colMeans(upper)           # proportion correct in the upper group
D <- p_upper - p_lower               # upper minus lower proportion

round(data.frame(p_upper, p_lower, D), 3)  # show the three columns

quantile() finds the cutoff scores. In items[total <= 3, ], the condition selects rows and the blank after the comma keeps all columns. Each group’s mean uses its own size as the denominator; the middle group is excluded.

Try it: Q3 was correct for 298/298 people in the upper group and 71/345 in the lower group. Calculate and interpret D.

Show answer

D = 1 − 71/345 = .794: the upper group’s proportion correct was 79.4 percentage points higher.

Positive D means the upper group performed better; near zero means little difference; negative D means the lower group performed better and warrants checking the item.

Note

All upper-group members scored 5/5, so p_upper is 1 for every item. Use the same groups for all items; different cutoff rules can change D.

3.2 Item/total score correlation

Correlate the 0/1 item score with the full total score. Pearson’s correlation for a binary item is called the point-biserial correlation, so we can use cor() directly.

# 3.2 Item/total score correlation ----
cor(items$Q3, total)  # point-biserial correlation for Q3

Q3 gives r = .618: people who got it right tended to have higher totals. Now repeat for all five items:

# Calculate the item-total correlation for each item.
r_total <- c(
  Q1 = cor(items$Q1, total),  # Q1 score and full total
  Q2 = cor(items$Q2, total),  # Q2 score and full total
  Q3 = cor(items$Q3, total),  # Q3 score and full total
  Q4 = cor(items$Q4, total),  # Q4 score and full total
  Q5 = cor(items$Q5, total)   # Q5 score and full total
)
round(r_total, 3)            # display the five correlations

A positive r indicates the expected relationship; near zero indicates little association; negative r indicates the opposite pattern. Unlike D, r uses everyone.

Note

The total includes the item itself, so the two scores overlap. If an item has no variation, its correlation is undefined.

4. Item reliability

Test reliability concerns consistency of test scores. The classical item reliability index combines how much an item varies with how strongly it relates to the total:

Item reliability index = item SD × item–total correlation

For example, SD = .50 and r = .60 give an index of .30. An item almost everyone gets right has little variation, so it contributes little to separating people.

# 4. Item reliability index ----
item_stats <- psych::describe(items)  # descriptive statistics for each item
item_sd <- item_stats$sd              # standard deviation of each item
names(item_sd) <- names(items)    # label the values Q1 to Q5
IRI <- item_sd * r_total          # use the correlations from Section 3.2

round(data.frame(item_sd, r_total, IRI), 3)  # show the ingredients and index

psych::describe() supplies each item’s SD. We multiply it by r_total from Section 3.2.

Try it: why is Q1’s index smaller than Q3’s?

Show answer

Q1 has less variation and a weaker item–total relationship: .265 × .362 ≈ .096, compared with .497 × .618 ≈ .308 for Q3.

Note

An index of .30 does not mean “30% reliable.” It is an item-analysis index, not a proportion of reliable variance or a test–retest estimate.

Discuss: must Q1 be removed because it is easy? Must Q3 be retained because its statistics are larger? What other information do you need?

Show possible answer

Neither decision follows automatically. Review the wording, answer key, content coverage, and test purpose. An easy item may assess essential knowledge; a large statistic does not guarantee relevant content.

Example write-up: Q3 had p = .553, upper–lower discrimination D = .794 using cutoffs 3 and 4, item–total r = .618, and an item reliability index of .308. Content review is also needed.

Optional: connect back to test reliability
# Optional: connect back to test reliability ----
analysis <- psych::alpha(items, check.keys = FALSE)  # keep original scoring
analysis$total$raw_alpha                    # alpha for all five LSAT items
round(analysis$alpha.drop$raw_alpha, 3)      # alpha without Q1, then Q2, etc.

Alpha is about .295 for this five-item set; removing any one item lowers it. Alpha describes a set of items, not a single item. This is not the reliability of the full LSAT.

Check yourself

  3. What two variables go into the item–total correlation?
  4. Item SD = .40 and item–total r = .50. What is the item reliability index, and does it mean “20% reliable”?
Show answers
  1. Easy: 90% answered correctly.
  2. D = .50.
  3. The item’s 0/1 scores and the full total scores, using all people.
  4. .40 × .50 = .20. No: the index is not a percentage of reliable variance.
