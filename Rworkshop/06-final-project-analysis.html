5. Display response frequencies, proportions, and plots

for (i in 1:ncol(data_items)) {
  frequency <- table(factor(data_items[, i], levels = 1:n_level))
  proportion <- rep(NA_real_, n_level)
  
  if (sum(frequency) > 0) {
    proportion <- as.numeric(prop.table(frequency))
  }
  
  cat("\nItem:", names(data_items)[i], "\n")
  cat("Missing responses:", sum(is.na(data_items[, i])), "\n")
  
  print(data.frame(
    Response = response_labels,
    Code = 1:n_level,
    Frequency = as.numeric(frequency),
    Proportion = round(proportion, 3)
  ))
  
  if (sum(frequency) > 0) {
    barplot(proportion,
            names.arg = response_labels,
            main = names(data_items)[i],
            xlab = "Likert response", ylab = "Proportion",
            ylim = c(0, 1), col = "lightblue")
  }
}

These describe original responses BEFORE reverse scoring or exclusions. Counts include every response category, even categories chosen zero times. Proportions use only people who answered that item: 0.25 means 25%. Missing counts are displayed separately and excluded from the denominator. An entirely unanswered item has NA proportions and no plot. Use the arrows in RStudio's Plots pane to view earlier item plots.

8. Use complete cases

analysis_items_set1 <- na.omit(scale_data_set1)

nrow(scale_data_set1)

if (nrow(analysis_items_set1) < 3 || ncol(analysis_items_set1) < 2) {

na.omit keeps only people who answered EVERY item in the selected scale. Missing responses in other scales do not affect this scale's sample. The two nrow results show the original and retained numbers of people. Note that complete-case analysis can lose information and introduce bias if missingness is systematic. 10. Calculate Cronbach's alpha

item_sd_set1 <- apply(analysis_items_set1, 2, sd)
item_sd_set1 # if any item has sd as 0, its correlation with other items cannot be defined 

if (any(item_sd_set1 == 0)) {
  stop("An item has no variation. Review item_sd_set1 before calculating alpha.")
}
if (sd(rowSums(analysis_items_set1)) == 0) {
  stop("Scale totals have no variation, so alpha is undefined.")
}

alpha_result_set1 <- psych::alpha(analysis_items_set1,
                             use = "complete.obs",
                             check.keys = FALSE,
                             delete = FALSE)
alpha_result_set1$total$raw_alpha

item_sd gives each item's standard deviation in the complete-case sample. An SD of zero means everyone gave the same scored response; that item's correlations are undefined. raw_alpha is Cronbach's alpha, a measure of internal consistency. use = "complete.obs" explicitly selects complete-case correlations. check.keys = FALSE prevents automatic reversal: follow the scoring manual.

Interpretation

Alpha summarizes internal consistency. It does not establish validity or prove that a scale measures one underlying characteristic. Inspect the item content and the intended use of the scores.

11. Examine item means, discrimination, and reliability indices

item_results_set1 <- alpha_result_set1$item.stats[, c("n", "mean", "sd", "raw.r", "r.drop")]

item_results_set1$item_reliability_index <- item_results_set1$sd * item_results_set1$raw.r
item_results_set1$corrected_item_reliability_index <- item_results_set1$sd * item_results_set1$r.drop

item_results_set1$alpha_if_deleted <- NA_real_
if (ncol(analysis_items_set1) >= 3) {
  item_results_set1$alpha_if_deleted <- alpha_result_set1$alpha.drop[
    rownames(item_results_set1), "raw_alpha"]
}

round(item_results_set1, 3)

n: complete-case sample size, the same for every item in this scale. mean: the mean scored response. For Likert items this is an endorsement or trait-level summary, NOT proportion correct or multiple-choice difficulty. sd: the spread of scored responses. raw.r: correlation with the total INCLUDING the item (overlap inflates it). r.drop: corrected item-total correlation, excluding this item from the total. A negative r.drop calls for review of scoring, wording, or scale membership. item_reliability_index = item SD x raw.r, the conventional item-total version. corrected_item_reliability_index = item SD x r.drop, the item-rest version. These are descriptive indices, not reliability coefficients for individual items, and need not lie between 0 and 1. State which version you report. alpha_if_deleted: alpha after removing each item. It is left NA for a two-item scale because removing one item leaves a single item. Use content and theory alongside these results; do not delete items merely to maximize alpha or an index. Negative alpha suggests checking the scale.

13. Correlate with another score

score_2_name <- "Other_score" # replace with the column name of your other score
score_2 <- as.numeric(data[, score_2_name]) # Excel columns were imported as text

# If using another scale calculated above, use this instead:
# score_2 <- rowMeans(scale_data_set2)

# score_2 must contain one value per ORIGINAL row, in the same person order.
# Keep the same people retained when calculating average_score_set1.
complete_set1 <- complete.cases(scale_data_set1)
cor(average_score_set1, score_2[complete_set1], use = "complete.obs")

# complete.obs also excludes people whose other score is missing.

Other_score is a numeric column in the practice workbook. For your own data, replace that name with the column you need.

Keep people aligned

The scale score has already lost incomplete rows. complete_set1 selects the matching rows of the full other-score column before correlating them. use = "complete.obs" then excludes missing other scores. Both columns must describe the same people in the same original row order.

Show example output
# Rounded Pearson correlation

The correlation uses 113 complete pairs: 115 people have complete set1 responses, and two of those people are missing Other_score. Higher set1 scores tend to accompany higher values of this other measure in the simulated data.

Check yourself

  1. Why do ID and age stay out of the item matrix?
  2. If someone answered Q1–Q3 but skipped Q5, do they remain in the set1 analysis?
  3. What is the difference between raw.r and r.drop?
  4. Why are there 115 people in the scale analysis but 113 in the final correlation?
Show answers
  1. They are metadata, not items measuring the scale.
  2. Yes. Complete cases are selected within Q1–Q3 for set1.
  3. raw.r includes the item in the total; r.drop correlates it with the rest of the items.
  4. Two people with complete Q1–Q3 responses have no Other_score, so they are excluded from the correlation.

For your project: report how responses were coded, which items were reversed, the scale’s complete-case sample size, score mean and SD, alpha, and any items needing review. For a correlation, report its own complete-pair sample size and the two measures used. A correlation does not establish causation.
