Workshop 4 — Test analysis

How do we turn survey answers into a test score, and how do we check whether that score is useful? We will use five neuroticism items from the bfi dataset in psych to describe the items, calculate a score, examine reliability, and check a prediction about validity.

Open a new R script called Workshop04.R. Run each section in order.

About the bfi dataset

The bfi dataset contains responses from 2,800 people collected through the Synthetic Aperture Personality Assessment (SAPA) project. It is included as an example dataset for learning about personality measurement.

Each row represents one person. The dataset has 28 columns: 25 personality items and three demographic variables, gender, education, and age. The personality items come from the International Personality Item Pool (IPIP), with five items for each of the Big Five traits:

ConscientiousnessC1–C5Being organized, responsible, and self-disciplined.C4, C5
ExtraversionE1–E5Being sociable, outgoing, and assertive.E1, E2
NeuroticismN1–N5A tendency to experience negative emotions, such as worry or irritability.None
OpennessO1–O5Being curious and receptive to ideas and experiences.O2, O5

The remaining columns describe the participants rather than personality traits:

Which items need reverse coding?

To make higher scores consistently indicate more of each trait, reverse-code A1, C4, C5, E1, E2, O2, and O5 before calculating trait averages or examining internal consistency. Keep the other personality items in their original direction. Demographic columns are not part of the trait scores.

These seven items are worded in the opposite direction from their trait. For example, agreeing that you do not talk much indicates lower extraversion. Reversing that response makes its scoring direction match the other extraversion items.

For a 1–6 scale, use reversed score = 7 − original score: 1 becomes 6, 2 becomes 5, and 3 becomes 4 (and vice versa). A missing response stays missing.

Optional example: reverse-code all seven items in a separate copy

Run this after loading bfi. Creating a fresh copy each time preserves the original responses and prevents accidentally reversing an already reversed score.

bfi_scored <- bfi
reverse_items <- c("A1", "C4", "C5", "E1", "E2", "O2", "O5")
bfi_scored[reverse_items] <- 7 - bfi_scored[reverse_items]

Use the five columns for the trait you want from bfi_scored. Do not average all 25 items into a single Big Five score.

For this workshop

None of N1–N5 needs reverse coding. Higher original responses already indicate greater neuroticism, so the analysis below uses these five columns directly from bfi.

Some responses are missing and appear as NA in R. We will use the five neuroticism items to create a score, then examine its relationship with age in years.

Source: bfi dataset documentation. Despite its name, this dataset should not be confused with the separately developed Big Five Inventory questionnaire.

Before you start

Start with an empty workspace and load psych. If you have not installed it, run install.packages("psych") once first.

rm(list = ls())         # clean start
options(scipen = 999)   # print full numbers
library(psych)          # for alpha() and the data

Clean start

rm(list = ls()) removes objects from your current R workspace. Save anything you need before running it. options(scipen = 999) discourages scientific notation; it does not change the calculations.

1. Read the survey

data(bfi) loads the example data, so no CSV file is needed. Each row is a person. We keep only the five neuroticism items, N1 to N5.

# 1. Read the survey ----
data(bfi)
survey <- bfi[, c("N1", "N2", "N3", "N4", "N5")]
head(survey)            # first six people

The items use a 1–6 response scale, from very inaccurate to very accurate. Higher responses on these five items indicate higher neuroticism; these items do not need reverse scoring. See the dataset documentation for the item wording and scoring key.

In bfi[, c(...)], the blank before the comma keeps every row, and the names after the comma select the columns. head(survey) shows the first six people.

2. Describe the items

# 2. Describing the items ----
psych::describe(survey)

There is one output row for each item. Start with these columns:

ColumnWhat it tells you
nNumber of non-missing responses for the item.
meanAverage response.
sdHow much responses vary.
min, maxLowest and highest observed responses. Check that they fall between 1 and 6.

Different values of n tell you that some people skipped different items.

3. One average score per person

rowMeans() works across each row to give one average score per person.

# 3. One average score per person ----
average_score <- rowMeans(survey, na.rm = TRUE)

psych::describe(average_score)
hist(average_score,
     main = "Neuroticism scores",
     xlab = "Average of 5 items (1-6)",
     col = "lightblue")

na.rm = TRUE averages the available responses when someone skips an item. If every item is missing, the result is NaN. This practice script does not require a minimum number of answered items; a real scoring plan should specify one.

The average stays on the 1–6 scale. In this dataset, M = 3.16 and SD = 1.20. The histogram shows how these scores are distributed across people.

4. Reliability

Internal consistency asks whether the items tend to work together as a scale.

Item correlations

# 4. Reliability ----
## Item correlation ----
round(cor(survey, use = "pairwise"), 2)

Look at the correlations away from the diagonal. Positive values mean that people who score higher on one item tend to score higher on another. The diagonal is always 1 because each item is correlated with itself.

use = "pairwise" uses the available responses for each pair of items. round(..., 2) displays two decimal places.

Cronbach’s alpha

## Cronbach's alpha ----
psych::alpha(survey)

The output is long. For this workshop, focus on raw_alpha in the first summary table: approximately 0.81.

AlphaRough guide
Below .60Poor internal consistency.
Around .70Acceptable internal consistency.
.80 or aboveGood internal consistency.

These are classroom guidelines, not universal cutoffs. Interpretation depends on the purpose of the score and the number of items.

Write-up: The five neuroticism items showed good internal consistency, Cronbach’s α = .81.

Reliability and validity

Alpha describes how consistently the items work together. A high alpha alone does not show that they measure the intended construct. The alpha documentation explains the other output fields.

5. Validity

Does the score relate to other things as expected? For this workshop, predict a small negative correlation between neuroticism and age: older people are expected to score a little lower.

Donnellan and Lucas (2008) found a slight negative association in their British sample, but a slight positive association in their German sample. The evidence was mixed, so treat the negative relationship as a prediction to check.

# 5. Validity ----
# Prediction: a small negative correlation with age.
cor.test(average_score, bfi$age)

bfi$age selects age from the original dataset. Its rows still match the people in average_score. cor.test() runs a Pearson correlation and uses people with both a score and an age.

OutputResultInterpretation
cor−0.117A small negative association.
p-value< .001Evidence against a zero population correlation.
95% confidence interval[−0.154, −0.081]The interval is entirely below zero.

Write-up: Neuroticism scores were slightly negatively associated with age, r(2798) = −.12, p < .001. Older participants tended to report slightly lower neuroticism.

This result is consistent with our prediction and provides one piece of validity evidence. It does not establish validity on its own, and a comparison of different people does not show that a person’s neuroticism decreases as they age.

Reference: Donnellan, M. B., & Lucas, R. E. (2008). Age differences in the Big Five across the life span: Evidence from two national samples. Psychology and Aging, 23(3), 558–566. https://doi.org/10.1037/a0012897.
