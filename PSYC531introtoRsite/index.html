PSYC531 — Introduction to R

About 3 minutes

R is free software for doing statistics. This guide teaches you enough to run the analyses in this course.

No programming background needed. If you can follow a recipe, you can do this. Take one lesson at a time, and type the code out yourself instead of just reading it.

Note

Versions we use (August 2026): R 4.6.1 and RStudio 2026.08.0. Install R first, RStudio second. Lesson 0 walks you through it.

Before your first lab

Five things to know before you start

  1. R is case-sensitive. mean works. Mean does not.
  2. Errors are normal. Everyone gets them, every day. They are messages, not failures.
  3. Read the error out loud. It usually names the problem: a missing bracket, a misspelled word.
  4. Searching is part of the job. Professional researchers look up R code constantly. Paste your error message into a search bar and you will usually find the answer.
  5. Click the grey triangles. Sections that say Show answer are hidden on purpose. Try first, then peek.

Where to get help

  • Inside R, type ?mean to open the help page for any function.
  • Posit cheat sheets — one-page summaries worth printing.
  • UCLA statistics help — worked examples of psychology analyses.
  • Stack Overflow — search your error message here.
  • Office hours. Bring your script and the exact error message.

Assignments, data files, and due dates are on Canvas. This site covers the software only.
